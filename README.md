## New Build Core Architecture Highlights

*   **Symmetrical Downward Pyramid Tech Grid:** A flexible layout engine that dynamically arranges tool-land-page cards into a strict row count on top (4 on desktop/tablet, 3 on mobile), automatically dropping and centering any leftover skills underneath in a balanced, identical size format.
*   **Compact App-Like Project Showcase:** Optimized card profiles with streamlined padding, tighter micro-typography, and downscaled image frames (140px desktop, 95px mobile) that drastically cut down vertical page length and eliminate scrolling fatigue.
*   **Seamless Mobile Canvas Vignette Overlay:** Re-engineered layered stacking sequence featuring an elliptical radial gradient alpha mask applied directly to the portrait image node. This completely dissolves harsh borders into a smooth white-to-blue background blend behind high-contrast floating link layers.
*   **Asynchronous Client-Side Category Filter:** A lightweight, offline-ready DOM manipulation script that allows users to instantly sort and filter project case studies across specific languages and software categories without requiring server requests.

## Local Installation Workspace

Follow these quick commands to spin up this portfolio project directly in your local development environment:

1. Clone this repository to your target workspace path directory folder:
   ```bash
   git clone https://github.com
   ```

2. Navigate inside the root cloned repository workspace path:
   ```bash
   cd portfolio
   ```

3. Launch your local tracking file environment:
   * **For HTML/CSS/JS:** Open `index.html` directly in your browser layout, or click `Go Live` on your VS Code status tracking taskbar using the Live Server extension.
   * **For PHP/MySQL features:** Move the target repository folder inside your local web server container directory (e.g., `XAMPP/htdocs` or `Laragon/www`), spin up XAMPP/Laragon, and import the provided `.sql` database schema file tracks.
