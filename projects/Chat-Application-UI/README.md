# Project:  Chat Application UI

A responsive chat interface built with Vanilla JavaScript. Simulates real-time messaging with auto-replies, typing indicators, and clean message bubbles.

## ✨ Features
- Message Bubble: Differentiated "sent" and "received" styles
- Send on Enter/Click: Full keyboard and mouse support
- Typing Indicator: Animated dots to simulate real-time response
- Auto Scroll: Always shows the latest message
- Mobile First: Full-screen on mobile, centered card on desktop

## 🛠️ Tech Stack
- HTML5
- CSS3 Flexbox
- Vanilla JavaScript ES6+
