# Project:  Chat Application UI

A responsive, WhatsApp-style chat interface built with Vanilla JavaScript, HTML5, and CSS3. Designed for my portfolio to showcase clean UI, DOM manipulation, and responsive design skills.

## ✨ Features
- Message Bubble: Differentiated "sent" and "received" styles with tail effect
- Send on Enter/Click: Full keyboard and mouse support
- Typing Indicator: Animated dots to simulate real-time response
- Auto Scroll: Always shows the latest message
- Mobile First: Rounded Full-screen card on mobile, centered card on desktop
- Modern UI: Dark theme, gradients, glassmorphism header, and smooth animations
- No Dependencies: 100% Vanilla JS

## 🛠️ Tech Stack
- HTML5: Semantic structure
- CSS3: Flexbox, CSS Variables, Media Queries, Animations
- Vanilla JavaScript ES6+: DOM manipulation, event handling, array methods

## How to Run
1. Clone the repo
2. Open `index.html` in your browser
   No build step or server needed.

## Concepts Practiced(learned)
- Managing state with a simple messages array
- Creating reusable render functions
- Handling responsive layouts with mobile-first approach
- Simulating async behavior with `setTimeout` for typing indicator
