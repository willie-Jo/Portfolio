# Calculator App

A fully functional calculator built with Vanilla JavaScript. Supports basic arithmetic operations and keyboard input.

## Features

- Basic operations: Addition, Subtraction, Multiplication, Division
- Clear and Delete functions
- Keyboard support for numbers and operators
- Responsive design for mobile and desktop 
- Dark / Light mode toggle

## Tech 

HTML5, CSS3, JavaScript

# How to Use 
1. Click butttons or use keyboard
2. Press `=` or `Enter` to calculate
3. Press `C` to clear
4. Click the toggle button for Dark/Light mode
