# Facebook Login Clone

A responsive UI clone of the Facebook login page. Focused on replicating the layout and styling.

## Features

- Accurate recreation of Facebook login layout
- Responsive design for mobile and desktop views
- Styled form inputs with hover and focus states
- "Create New Account" and "Forgot Password" links

## Tech Stack

HTML5, CSS3

## Note

This is a UI clone for learning purposes only. No backend functionality.
