# Image Slider / Carousel

A responsive, auto-playing image slider built with Vanilla HTML, CSS, and JavaScript.

### Features
- Auto-Play: Slides change automatically every 3 seconds
- Manual Controls: Prev/Next buttons for user navigation
- Dot Navigation: Click dots to jump to any slide
- Dynamic Captions: Text description updates with each slide
- Pause on Hover: Auto-play pauses when you hover over the slider
- Fully Responsive: Looks great on Desktop, Tablet, and Mobile
- Smooth Transitions: CSS transitions for sliding and caption fade

### Tech Stack
- HTML5 - Semantic Structure
- CSS3 - Flexbox, Responsive Design, Transitions
- Vanilla JavaScript - DOM Manipulation, Event Listeners, setInterval

### How to Use
1. Clone the repo
2. Open `index.html` in your browser
3. To add your own images: Replace the `src` in the `<img>` tags
4. To add your own captions: Change the `data-caption` attribute
