# Project: E-commerce Product UI

A responsive e-commerce product grid built with vanilla JavaScript. Features dynamic product rendering, category filter, cart state, and mobile-first layout. Designed to demonstrate modern CSS and DOM manipulation skills.

## Features
- Dynamic Product Grid: Renders products from a JS array using `map()` and template literals
- Category Filtering: Sidebar with "All, Audio, Computer" filters and active state highlight
- Responsive Layout: 3-column grid on desktop and tablet, 2-column grid on mobile
- Add to cart: Updates cart counter in header with simple state management
- offline Ready: Uses local images in `/assets` folder for reliable screenshots
- Clean UI: CSS Grid, Flexbox, CSS variables for theming and hover effects 

## Tech Stack
- HTML5: Semantic structure with `header`, `aside`, `main`, `section`
- CSS3: CSS Grid, Flexbox, Media Queries, CCS Variables
- Vanilla JavaScript ES6+: Array methods `filter()`, `map()`, DOM updates, event handling

## How to Run
1. Clone the repo
2. open `index.html` in your browser.

## Concepts Practiced(learn)
1. Component Rendering: Building UI from data arrays
2. State & Filtering: Managing `cart` array and `currentFilter` state
3. Responsive Design: Mobile-first approach with 3 breakpoints
4. UX Details: Active button states, hover effects, no horizontal scroll
5. File Organization: Separating assets for offline/portfolio use
